# Практическое задание. Поиск по строкам журнала

**Цель**

Связать время жизни результата с исходным текстом и проверить, какие ссылки остаются действительными после выхода из области видимости.

**Задание**

1. Создать структуру `Log<'a>`, которая хранит заимствованный текст `&'a str`. Конструктор принимает строковый слайс.
2. Реализовать метод `find_first(&self, prefix: &str) -> Option<&'a str>`. Метод возвращает первую строку, которая начинается с заданного префикса, или `None`.
3. Для текста `INFO запуск\nWARN таймаут\nWARN повтор` проверить, что префикс `WARN` даёт `Some("WARN таймаут")`, а `ERROR` даёт `None`.
4. В тесте создать журнал и строку-префикс внутри блока. Вынести результат поиска из блока и проверить его после выхода. Исходный текст хранить во внешней области в переменной типа `String`.

**Подсказки по ключевым частям**

- `lines()` отдаёт слайсы исходного текста, а `starts_with()` проверяет префикс.
- В возвращаемом `&'a str` аннотация `'a` указывает на исходный текст. Ссылка на `self` и префикс могут иметь более короткие времена жизни.

**Что проверить перед отправкой**

- [ ] Результат используется после выхода из блока, где созданы `Log` и префикс.
- [ ] При нескольких совпадениях возвращается первая строка. Пустой текст и префикс без совпадений дают `None`.
- [ ] Поиск обходится без копирования строк, `cargo test` проходит.

**Советы по улучшению работы**

Добавить документационный тест `compile_fail`, в котором результат поиска пытаются использовать после освобождения исходного текста.
