# Практическое задание. Конвертер минут

**Цель**

Подготовить рабочее окружение и пройти цикл от создания проекта до запуска собранной программы.

**Задание**

1. Проверить доступность инструментов командами `rustc --version`, `cargo --version` и `rustfmt --version`.
2. В отдельной папке создать проект `cargo new minutes_converter`. Открыть его в VS Code и выполнять команды из папки с его `Cargo.toml`.
3. В `src/main.rs` написать программу, которая хранит число `125` в переменной, переводит минуты в часы и минуты и выводит `2 ч 5 мин`.
4. Выполнить `cargo fmt`, `cargo check`, `cargo build` и `cargo run`. Запустить собранный файл напрямую из PowerShell командой `.\target\debug\minutes_converter.exe`.

**Подсказки по ключевым частям**

- Целочисленное деление на `60` даёт часы, остаток от деления — минуты.
- `cargo check` проверяет код, а `cargo build` создаёт исполняемый файл.

**Что проверить перед отправкой**

- [ ] Проект содержит `Cargo.toml` и `src/main.rs`.
- [ ] `cargo fmt --check` и `cargo check` проходят, оба способа запуска дают одинаковый вывод.
- [ ] При подстановке `0`, `59` и `60` получаются `0 ч 0 мин`, `0 ч 59 мин` и `1 ч 0 мин` соответственно. В отправляемой версии используется `125`.

**Советы по улучшению работы**

Вынести число минут в часе в именованную константу. Записать в README проекта команды проверки и запуска.
